# 歌曲语言学习软件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建可用于学习开发的 Flutter 项目，并如实验证本机能够运行的平台。

**Architecture:** 单个 Flutter 客户端，按歌曲库、练习和纯 Dart 领域模型分离。本地解析歌词，不依赖后端启动。未来音频处理服务只保留说明。

**Tech Stack:** Flutter stable 自带 Dart、Material 3、跨平台 file_selector、flutter_test、Git。

**Spec:** [首版设计与环境检查](首版设计与环境检查.md)

## Global Constraints
- Flutter + Dart 客户端，本地优先，面向 Android、iOS、Windows、macOS 和 Web。
- 不将演示计时器描述为真实音频播放。
- SDK 不提交到 Git。
- 首版不承诺跨重启持久化或完整歌曲播放。
- 任何安装失败均保存真实错误，不以生成脚本代替执行成功。

## Review Focus
- 空白或 BOM 歌词：显示空文件提示，不进入空练习。
- LRC 多时间戳、元数据及异常时间：正确排序并明确拒绝无效内容。
- 用户取消文件选择：保持当前歌曲和页面状态。
- 练习首尾及切换歌曲：按钮边界正确，进度重置。
- 窄屏和长歌词：可滚动，无布局溢出。

## Task 2：歌词模型与解析
**Files:** `client/lib/domain/lyric_line.dart`、`client/lib/domain/lyric_parser.dart`、`client/test/domain/lyric_parser_test.dart`。
**Interfaces:** `LyricLine({required String text, Duration? timestamp})`；`List<LyricLine> parseLyrics(String content, {required bool isLrc})`，空内容或无可用行抛出 `FormatException`。
- [ ] 写测试：TXT 空行忽略、BOM 去除、保留中文；LRC [00:01.50] 等于 1500ms；同一行多个时间戳展开并排序；元数据忽略；空文件与异常时间拒绝。
- [ ] 运行 flutter test test/domain/lyric_parser_test.dart，确认因模型/解析器尚未实现而失败。
- [ ] 实现上述接口；LRC 秒数限制 0–59，支持百分秒或毫秒，不为 TXT 编造时间轴。
- [ ] 重跑解析测试，全部通过后提交该功能。
